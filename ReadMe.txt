操作方法
　クリック長押しでチャージ（最大2秒）
　　チャージに応じて弾の威力が変わる
　クリックを離すと弾が発射

バグリスト対応
　ダメージが毎フレーム発生
　　攻撃モーションでの対応
　熊の重なりがおかしい
　ゲームが終了できない
　リザルトがない
　　リザルト画面の追加
　オブジェクトが残っている
　お社をスルーする熊がいる
　スタートボタンとゲーム内操作に一貫性がない
　
その他追加要素
　敵が2種類
　　敵1:ひっかき攻撃
　　敵2:エルボーで突進 お社に衝突後、跳ね返る
　お社のHPバーを追加
　　画面下部に存在
